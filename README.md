# Project UHS: Student Portal

A professional student portal landing page for the University of Health Sciences (UHS), Lahore.

## Features
- **Official Branding**: Maroon and Forest Green theme matching the UHS website.
- **Student Profile**: Detailed academic and personal information.
- **Academic Tracking**: Progress indicators for Professional Examinations.
- **Transfer Portal**: Integrated document viewer for college transfer applications.

## Technical Details
- **Frontend**: HTML5, CSS3.
- **Style**: Traditional institutional design.
